# Deliverable spec: worked example

Produce one small local repository package containing:

- `README.md`: problem, architecture, graph model, Copilot workflow, setup, and
  expected result;
- synthetic requirements, decisions, code, tests, ownership, and policy data;
- a versioned graph representation with stable ids, typed edges, provenance, and
  update behavior;
- minimal ingestion and query code;
- reviewed Copilot instructions/prompts/agent configuration appropriate to the
  demonstrated surface; and
- one command that runs deterministic checks, including a stale or conflicting
  context case.

Show the same bounded task with and without graph context and report what changed.
No live GitHub, X, enterprise, or paid-service credentials may be required.

# Deliverable spec: tutorial

Produce a self-contained Markdown tutorial with:

1. the engineering problem, learner prerequisites, and observable outcome;
2. a precise graph-kind definition and minimal node/edge/provenance model;
3. a synthetic enterprise-delivery scenario;
4. a step-by-step GitHub Copilot Chat or coding-agent workflow, including the
   exact repository context/customization used and its permission boundary;
5. compact schemas, queries, prompts, and code that readers can copy;
6. verification, failure modes, stale-context handling, and security notes;
7. an exercise and answer key; and
8. primary-source references with retrieval dates.

Any executable snippets must have a documented local check. Distinguish product
facts, observed evidence, design recommendations, and hypotheses.

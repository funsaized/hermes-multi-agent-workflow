# Deliverable spec — hands-on lab

Produce `README.md`, starter files, `solution/`, `sources.md`, and the smallest
runnable `verify` script appropriate to the environment.

The README must define behavioral objectives, Skills Map placement, prerequisites,
diagnostic, setup, exercise sequence, expected observations, debugging/failure
exercise, independent task, completion criteria, and cleanup. Keep useful
difficulty in the engineering problem while removing avoidable setup and source-
hunting friction. Verification must fail when the target capability is absent.

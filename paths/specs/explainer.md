# Deliverable spec — explainer

Produce `explainer.md`, `self-check.md`, `source-ledger.md`, and
`dependency-map.mmd`. Add `slides.html`, `script.md`, or files under `visuals/`
only when a visual presentation materially clarifies the approved mental model.

Move one reasoning step at a time from current to target capability. State the
misconception each step corrects, use consistent terminology, include worked
predictions or examples, and end with active checks rather than “does this make
sense?” Every material claim must map to the dated source ledger.

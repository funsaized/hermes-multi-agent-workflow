# Deliverable spec — full course

Produce a `course/` directory containing `README.md`, `learner-profile.md`,
`dependency-map.mmd`, `diagnostic.md`, `modules/`, `capstone/`, `assessments/`,
`instructor-guide.md`, `source-ledger.md`, and a runnable `verify-course` check.

Each module declares incoming capability, target capability, dependencies, one
central reasoning step, worked example, practice, evidence of understanding, and
remediation. The course must avoid reteaching demonstrated capabilities, never
jump over an unstated prerequisite, and culminate in an authentic software-
engineering performance task.

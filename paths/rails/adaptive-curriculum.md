# Adaptive curriculum scope rails

- Build a local file-based curriculum navigator, not a SaaS application.
- Use Python's standard library; add no database, web UI, accounts, analytics,
  telemetry, cloud deployment, or network dependency.
- Store only synthetic learner states used for tests; collect no personal data.
- Branch only on demonstrated capabilities and assessment evidence.
- Never let a model mark its own unsupported explanation as a learner pass.
- Simulate multiple learner paths and remediation before delivery.
- A failed test or unreachable curriculum node blocks delivery.

# Explainer scope rails

- Produce local Markdown, Mermaid, self-contained HTML, scripts, and static visual
  assets only; publication and recording are outside scope.
- Teach only the approved blocking mental model and necessary prerequisites.
- Keep vocabulary stable while preserving meaningful source disagreements.
- Do not use confidence questions as evidence of understanding.
- Create a visual only when it clarifies a relationship that prose does not.
- No external uploads, accounts, tracking, paid assets, or unapproved services.
- The reviewer blocks factual, pedagogical, or accessibility failures.

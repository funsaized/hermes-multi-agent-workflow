# Hands-on lab scope rails

- Build a small local lab, documentation, and runnable verification only.
- Prefer the standard library and already-installed dependencies.
- Use synthetic, public, or explicitly approved data.
- No production databases, cloud mutation, deployment, telemetry, auth flows,
  purchases, or credentials beyond those explicitly approved and provisioned.
- Mock external systems unless the learning objective requires live access.
- Commands must be reproducible from the persistent workspace.
- A failed check blocks delivery; never report a false pass.
